# LockCanvas アート方針（ART_DIRECTION）

基準日：2026-11-23 JST（正本）

## 1. 世界の言葉
- **雰囲気キーワード**：
  1. **静謐なアトリエ**：UI自体は黒子に徹し、ユーザーが作るロック画面キャンバスを最も鮮やかに引き立てる。
  2. **触ってすぐ分かる**：説明文を読ませず、視覚プレビューと短い1行ヒント・直接操作で初心者でも迷わない。
  3. **端まで美しい余白**：画面最下部までエッジトゥエッジで使い切り、意味のない黒い隙間や重なりを作らない。
- **やらない雰囲気**：
  - 派手な装飾グラデーションや過剰なカード乱立（作品の邪魔になる）
  - 専門用語や内部件数の羅列（初心者の認知負荷を上げる）

## 2. 色の性格
- **土台（暗黒オブシディアン系）**：`background` / `surface` / `surfaceContainer` の3段の静かな明度差だけで階層を作り、キャンバス作品の発色を最大化。
- **主役アクセント（澄んだスカイブルー 1色）**：最重要な1アクション（保存、新規作成、選択中インジケータ）にのみ使用。
- **補助アクセント（ラベンダー・エメラルド）**：`FilledTonalButton`（壁紙設定）や選択ピル（`secondaryContainer`）で穏やかに強調。
- **危険色（コーラルレッド）**：削除・初期化のみに限定し、主要ボタンと物理的に離す。

## 3. 形の言語
- **角丸**：大コンテナ `18〜20dp`、ボタン・小カード `12〜14dp`、バッジ・ピル `99dp`（3段階に固定）。
- **区切り**：影を乱用せず、`1dp` の極細 `outlineVariant` と面の色差で静かに区切る。
- **アイコン**：Material Rounded / Outlined を一貫使用し、48dp以上のタッチ領域を必ず確保。

## 4. 画面ごとの意味
| 画面 | 一番見せたいもの（主役） | 狙う気持ち | 主な手段 |
|---|---|---|---|
| **ホーム** | 保存済みデザインギャラリー | 「自分の作品を眺めて、すぐ作り変えたい」 | 2列フル活用グリッド＋新規作成カード、未設定時のみ1行バー |
| **エディター** | ロック画面ライブキャンバス | 「思い通りに動かせて楽しい、迷わない」 | 画面いっぱいのキャンバス、1行操作ヒント、エッジトゥエッジ下ドック |
| **設定と仕様** | 必須制約と壁紙設定アクション | 「仕組みがすぐ分かり、安心して使える」 | 1画面完結の `ListItem` 4項目＋下部固定アクションバー |
