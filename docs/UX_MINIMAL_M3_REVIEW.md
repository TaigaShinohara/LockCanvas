# LockCanvas UX・情報量削減・Material Design 3 見直し記録

基準日：2026-11-23 JST  
対象：LockCanvas Androidアプリ全体（`HomeScreen` / `EditorScreen` / `SettingsInfoScreen` / `Theme`）

---

## 1. concept-driven-ux（コンセプト起点の体験見直し）

### コンセプト（正本）
> 「ロック画面を、自分だけの自由なキャンバスに。」  
> ［Androidユーザー］が［日常の隙間時間や気分転換の場面］で［直感的な自由配置と動的データでデザインを編集しロック画面へ反映する］ことで［端末を開くたびに自分の表現と必要な情報が一目で分かる心地よさを感じる］体験。

### 既存機能の維持・変更・統合・削減の比較
| 対象 | 判定 | 理由と改善内容 |
|---|---|---|
| ホーム上部の大きな「ライブ壁紙未設定」カード | **変更（圧縮）** | 主役のデザイン一覧より大きく目立っていたため、未設定時のみ1行スリムバーへ圧縮。設定済み時はTopAppBarのアイコンへ縮退。 |
| エディター「保存」後の壁紙設定導線 | **変更（統合）** | ライブ壁紙未設定時に保存しても反映されない断絶があったため、Snackbarに「ロック画面に設定」アクションを追加し1タップでピッカーへ直行可能に。 |
| キャンバス空白タップ時のパネル連動 | **変更** | 要素選択解除時に開いていた編集パネルも自動で閉じ、キャンバスを広く確認できるように改善。 |
| 設定画面の4枚の長文説明カード | **削減・統合** | 説明書化していた450文字超の文章を、M3 `ListItem` の4項目（各1行）へ圧縮。 |

## 2. minimal-information-design（必須／支援／ノイズ仕分けと削減）

### コンセプト仕分け対照表（代表項目）
| 区分 | 項目 | 判定文／行き先 |
|---|---|---|
| **必須 (A)** | 保存済みデザインサムネイル一覧 | 無くなると「デザインを選び編集する」行為が成立しない |
| **必須 (A)** | 自由配置キャンバス＆5ツールタブ | 無くなると「自分だけの自由なキャンバス編集」が成立しない |
| **支援 (B)** | ライブ壁紙未設定バー／壁紙ピッカー導線 | 必須の「ロック画面へ反映」を助ける（未設定時のみ1行表示） |
| **支援 (B)** | 条件シミュレーター／セーフエリアガイド | 必須の「動的変化・OS領域回避」を助ける（必要時のみ展開） |
| **ノイズ（削除）** | カード下の「要素 5 ・ ルール 2」 | 内部データ件数であり視覚プレビューと重複 → **削除** |
| **ノイズ（削除）** | 「保存済みデザイン」「3件」見出し＆件数 | グリッドを見れば分かる重複表示 → **削除** |
| **ノイズ（削除）** | ホーム未設定バナーの補足長文 | 見出し＋「設定する」ボタンで3秒理解可能 → **削除** |
| **ノイズ（阻害・削除）** | エディター上部の常時「条件ルール一致: 1件」ピル | キャンバス上部を遮蔽するため削除し、ルールタブの極小ドットへ置換 |
| **ノイズ（重複・削除）** | 「（画面OFF時は自動停止）」「電池残量や時間帯を変えて〜」 | 設定画面・操作UI自体と重複するため削除 |

### 削減前後の比較（概算）
- **ホーム画面**：常時可視テキスト 約95文字 → 約40文字（約58%削減）、カード内メタノイズ 100% 削除
- **設定画面**：可視テキスト 約450文字 → 約130文字（約71%削減）、カード乱立 4枚 → 0枚（`ListItem` 化）
- **エディター画面**：キャンバス上の常時オーバーレイピル 1個 → 0個（シミュレーター時のみ表示）

## 3. material-design-3-ui（M3準拠・アクセシビリティ・自己監査）

### 実装済みの改善
1. **状態と言葉の統一**：
   - ホームは「選択中」「壁紙に反映中」を明確に分け、未選択デザインは「選ぶ」操作で選択する。
   - エディターは「保存済み／保存が必要／保存して反映」を表示し、保存後Snackbarは反映済みまたは壁紙設定が必要で分岐する。
   - ホームカードはプレビューの編集導線と選択操作を分離し、重複する入れ子クリックを解消した。
2. **初心者導線と情報整理**：
   - 要素選択時はキャンバス操作ヒントと「編集する」の導線を表示し、編集パネルへ自然に移動できる。
   - 動的テキストは生トークンではなく「現在時刻・日付・電池残量・充電状態」を選択できる。
   - セーフエリア案内、画像選択、保存状態を日本語の操作説明へそろえた。
   - 条件ルールは「このとき／すると」に変更し、対象要素をチップで選択できる。複数ルール一致時は登録順に適用される挙動を説明した。
   - レイヤーと詳細ツールはタブ内へ残し、必要時だけ表示する。
3. **アクセシビリティ**：
   - 保存・レイヤー操作・ドック・ルール削除・スライダーに48dp以上の操作領域を適用した。
   - 色スウォッチは32dp以上とし、選択時の枠・チェックで状態を示す。
   - アイコンボタンには操作内容が分かる読み上げテキストを維持した。
4. **設定と仕様**：
   - 「仕様」「ヘルプ」「危険な操作」を分け、プリセット初期化はカスタムデザイン削除の警告付きで分離した。
   - オンボーディングの12ページ化・自動遷移・称賛演出は変更していない。

### M3 自己監査スコア（0 / 1 / 2）
| カテゴリ | スコア | 根拠 |
|---|---|---|
| Task clarity | 2 | ホームはデザイン選択＋新規作成、エディターはキャンバス編集に集中 |
| Information hierarchy | 2 | 主役（サムネイル／キャンバス）と補助（Tonalボタン／折りたたみパネル）が明確 |
| Component semantics | 2 | `ListItem`、`FilledTonalButton`、`ExtendedFAB`、`Role.Tab` が役割一致 |
| Token discipline | 2 | `MaterialTheme.colorScheme` と M3 `Typography` に統一 |
| Adaptive behavior | 1 | モバイル縦画面は最適化済み。タブレット2ペイン対応は Phase 4 課題 |
| States & feedback | 2 | 未設定／選択中／壁紙反映中／保存済／保存必要を画面ごとに一貫表示 |
| Accessibility | 2 | 主操作48dp以上、スライダー・スウォッチ・アイコンの操作領域を拡張し、選択状態を非色でも表示 |
| Expressive restraint | 2 | 装飾を抑え、ユーザーのキャンバス作品自体が引き立つ落ち着いたUI |

## 4. コンセプト達成の最終照合
- **誰が・どんな場面で**：Androidユーザーが空き時間にロック画面をデザインする（設計・実機導線：実現）
- **何をする**：自由配置・動的データ・条件ルールを編集し、壁紙ピッカー経由でロック画面へ反映（実機動作確認：実現）
- **どんな気持ちになるか（ワクワク・心地よさ）**：人間による実使用評価は **未確認**（AIの動作確認だけで達成扱いにしない）
