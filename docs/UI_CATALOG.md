# LockCanvas UIカタログ（UI_CATALOG）

基準日：2026-11-23 JST（主要パーツ正本）

| パーツ名 | 役割 | 使う場面 | 状態 | アート方針との対応 |
|---|---|---|---|---|
| `WallpaperStatusBanner` | ライブ壁紙未設定時の1行案内＋設定導線 | ホーム画面最上部（未設定時のみ） | 通常／押下 | `surfaceContainer` + `FilledTonalButton` で作品を邪魔しない |
| `DesignThumbnailCard` | 保存済みデザインのライブ描画カード | ホーム画面2列グリッド | 通常／選択中／適用中 | サムネイル主役、1行タイトル（省略なし）＋48dpメニュー |
| `CreateDesignCard` | 新規キャンバス作成カード（新規登録） | ホーム画面2列グリッド末尾 | 通常／押下 | 点線枠＋`+`アイコンでグリッドの空きを埋め、初心者にも直感的 |
| `InteractiveCanvasStage` | 実機同等の自由配置キャンバス | エディター中央（最大面積） | 未選択／選択中／ドラッグ中／スナップ中 | 画面いっぱい活用、セーフエリアガイド・中央スナップ線 |
| `EditorGuideStrip` | 初心者向け1行操作ガイド（新規登録） | エディターキャンバス直下（パネル閉時） | 未選択／選択中 | 1行で直接操作（タップ・ドラッグ・2本指）を迷わず伝達 |
| `BottomToolDock` (`DockTabItem`) | 5カテゴリのツール切替バー | エディター最下部（エッジトゥエッジ） | 未選択／選択中／ルール一致ドット | `navigationBarsPadding` 内包で下部隙間ゼロ、48dp以上＋M3ピル |
| `ExpandableToolPanel` | 選択タブの詳細ツールパネル | ドック直上（`AnimatedVisibility`） | 開／閉 | 必要な時だけ段階表示し、48dp閉じるボタン完備 |
| `SpecListItem` | 制約・仕様の1行サマリー | 設定と仕様画面 | 通常 | カード乱立を避け M3 `ListItem` + `HorizontalDivider` で静かに整理 |
| `BottomActionBar` | 画面下部固定の主要・補助アクション枠 | 設定と仕様画面最下部 | 通常／押下 | エッジトゥエッジで下部隙間を解消し片手操作性を確保 |
