# LockCanvas 初回オンボーディング ページ地図

基準日：2026-11-23 JST / 版：`v1`（体験直結型）

## 4つの達成条件
1. **何のためのアプリか**：「ロック画面を、自由配置とリアルタイム情報で彩るライブ壁紙キャンバス」
2. **基本的な使い方（ちょうど3ステップ）**：1. ベースを選ぶ → 2. 指で動かす → 3. 保存してロック画面に設定する
3. **ワクワクする瞬間**：P5（バッテリー・充電で動くデモ）、P10〜P11（本物と同じドラッグ試し操作と成功結果）
4. **早く使いたい（直結）**：P12の完了ボタンで、選んだ好みに合うデザインをエディターで即座に開く
